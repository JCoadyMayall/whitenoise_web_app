A web app created with the Django framework and deployed on Render - https://whitenoise-app.onrender.com/

This is a simple white noise app; it includes several different white noise sounds that can be activated with the individual "play" buttons, and loop until stopped with the "Stop" button.

The idea for this app came about as all other white noise apps I had used were riddled with ads that would (sometimes) play sound at significant volume and disturb my sleeping baby - I simply wanted an ad-free white noise app and wanted to practice using Django.
